# Storybook Bootstrap 5

A **Storybook 10** workspace for building and documenting UI components with **Twig** templates and **Bootstrap 5**, designed to be reused in a Drupal theme.

- **Storybook** `@storybook/html-vite` (HTML + Vite)
- **Twig** compiled by `vite-plugin-twig-drupal` (Drupal Twig extensions provided locally by `packages/drupal-twig-extensions`)
- **Bootstrap 5** + **Bootstrap Icons**
- **Gulp** for assets: Sass (`gulp-sass` + `autoprefixer` + `cssnano`) and JS (`gulp-concat` + `gulp-terser`)
- **Vitest** + Playwright for story tests (`@storybook/addon-vitest`)

## Requirements

- [DDEV](https://ddev.com/) (recommended), or
- Node.js **22** (see `.nvmrc`) if you run the commands outside DDEV

## Installation

```bash
git clone git@github.com:Greg735/sb-bootstrap5-base.git
cd sb-bootstrap5-base
ddev start
ddev npm install
```

DDEV installs the Playwright Chromium browser on start (needed for `npm test`).

## Development

| Command | Description |
| --- | --- |
| `ddev npm run develop` | Gulp (build + watch) and Storybook together |
| `ddev npm run storybook` | Storybook only, on port `6006` |
| `ddev npm run gulp` | Gulp only: build assets, then watch |
| `ddev npm run build-storybook` | Static build into `storybook-static/` |
| `ddev npm test` | Run story tests with Vitest (headless Chromium) |
| `ddev npm run test:watch` | Vitest in watch mode |

Without DDEV, drop the `ddev` prefix (`npm run develop`, …).

With DDEV, Storybook is available at **https://sb-bootstrap5-base.ddev.site:6006**.

> Storybook loads `/css/style.css` and `/js/sb-main.js` from `public/`, which are generated by Gulp. If styles or JS behaviors are missing, run `ddev npm run gulp` (or use `develop`).

## How it works

### Gulp

The default Gulp task:

1. cleans `dist/`
2. copies Bootstrap Icons fonts and custom fonts
3. compiles `stories/main.scss` → `public/css/style.css` and `dist/css/style.css` / `style.min.css`
4. bundles vendor JS (Bootstrap, Leaflet, scrollCue, GLightbox, Masonry) and all `*.behaviors.js` → `public/js/sb-main.js` and `dist/js/` (+ `.min.js`)
5. copies component Twig templates to `dist/components/` (relative includes rewritten to `@components/…`)
6. copies images from `public/img/` to `dist/img/`
7. watches SCSS, `*.behaviors.js` and Twig files

Watched files:

- `stories/main.scss`, `stories/{foundations,components}/**/_*.scss`
- `stories/{foundations,utilities,components}/**/*.behaviors.js`
- `stories/components/**/*.twig`

### Twig templates

- `*.twig` → distributable component templates, copied to `dist/components/`
- `*.local.twig` → story/demo examples only, **not** copied to `dist/`

### JavaScript behaviors

Component JS lives in `*.behaviors.js` files and uses `Drupal.behaviors` + `once()` (never `DOMContentLoaded`). In Storybook, `.storybook/preview-head.html` provides a minimal `Drupal` / `once()` shim so behaviors run as they would in Drupal.

## File structure

```
├── .ddev/                  # DDEV configuration
├── .storybook/             # Storybook configuration (main, preview, manager theme)
├── stories/                # Source files
│   ├── main.scss           # Main Sass entry point
│   ├── assets/             # Static assets served at /assets
│   ├── documentation/      # Documentation stories (introduction…)
│   ├── foundations/        # Design primitives: colors, typography, headings, forms…
│   ├── utilities/          # Shared helpers: animations, icons, masonry, tooltips
│   └── components/         # Reusable UI components
├── public/                 # Generated by Gulp, served by Storybook (do not edit)
├── dist/                   # Generated distributable output: css, js, components, img (do not edit)
├── storybook-static/       # Generated static Storybook (ignored)
├── gulpfile.js             # Gulp tasks
├── vitest.config.js        # Vitest / story tests
└── package.json
```

## Adding a component

Create a folder `stories/components/<name>/` with only the files you need:

```
<name>.twig            # Template (distributed)
_<name>.scss           # Styles ("_" prefix required by the watcher)
<name>.stories.js      # Stories
<name>.docs.md         # Documentation (optional)
<name>.behaviors.js    # Behavior using Drupal.behaviors + once() (optional)
```

Register the styles in `stories/components/_index.scss`:

```scss
@import '<name>/<name>';
```

Stories follow this pattern:

```js
import template from './example.twig';
import source from './example.twig?raw';

export default {
  title: 'Components/Example',
  parameters: {
    componentSource: { code: source, language: 'twig' },
  },
};

const Template = (args) => template(args);

export const Default = Template.bind({});
Default.args = { /* … */ };
```

## Generated files

Do not edit `public/css/`, `public/js/`, `dist/` or `storybook-static/` by hand: change the sources in `stories/` (or `gulpfile.js` / `.storybook/`) and rebuild. Note that `dist/` is versioned, so check `git status` after a build.
